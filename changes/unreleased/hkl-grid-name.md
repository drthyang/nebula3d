- **HKL grid, not Unit cell, on the r.l.u. views.** The switch that draws
  dashed lines at integer h, k, l was named *Unit cell* on Reciprocal
  cleanup, the Bragg page and the Q–R page, though those lines are not a
  unit cell. It is now *HKL grid* there, as on the Configure preview. The
  real-space views (3D-ΔPDF, multi-volume) keep *Unit cell*, where the lines
  are the cell's edges. It is still one setting, stored as before, so saved
  sessions and the browser's remembered setting load unchanged.
