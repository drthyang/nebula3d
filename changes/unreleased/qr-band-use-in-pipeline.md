- **Q–R page: Use in pipeline.** Applying a |Q| band on the Q–R page
  recomputes that page's round trip only, and Save ΔPDF writes a file of its
  own, so the 3D-ΔPDF page kept showing the full-band ΔPDF. A row under the
  page's header now shows the |Q| band the pipeline's ΔPDF is made with.
  Use in pipeline sets Configure's ΔPDF |Q| band to the band applied on the
  page, and the stage track marks the ΔPDF stale. Run from ΔPDF then makes
  the one ΔPDF that the 3D-ΔPDF page, the Q–R page and the Pilot all read.
  The change is listed in the NEBULA Pilot's Changes list and the report as
  yours, and Undo, on the page or in the list, puts the earlier band back.
  The |R| band stays on the Q–R page, because the pipeline has no step that
  masks the ΔPDF after the transform. The row says so while an |R| band is
  applied. Save ΔPDF is unchanged.
